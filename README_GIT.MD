# Merge `main` branch into your `property-leasing`

1. **🔄 Switch to the `property-leasing` branch**:

   ```bash
   git checkout property-leasing
   ```

2. **⬇️ Pull the latest changes from the `main` branch**:

   ```bash
   git pull origin main
   ```

3. **🖋️ Press `Ctrl + Shift + G`** to open the Git panel and edit the files you want to merge. You can discard any unwanted changes.

4. **🚀 Push the merged changes to the `property-leasing` branch**:

   ```bash
   git push origin property-leasing
   ```
